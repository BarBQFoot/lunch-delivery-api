# ค้นหาออเดอร์ใกล้เคียงตามระยะทางถนน

`GET /orders/nearby?lat=13.7563&lng=100.5018`

- `lat` และ `lng` คือพิกัดละติจูดและลองจิจูดของจุดเริ่มต้น
- ส่งข้อมูลออเดอร์และลูกค้าในรูปแบบเดิม พร้อมฟิลด์ `distance_km` โดยเรียงระยะทางจากน้อยไปมาก
- แสดงเฉพาะออเดอร์ที่มี **ระยะทางตามถนนไม่เกิน 2 กม.** ซึ่งเป็นเกณฑ์ระยะทางเดียวกับ API เดิม
- ใช้ OSRM Table กับรูปแบบการเดินทาง `driving` ระยะทางที่ได้เป็นระยะของเส้นทางขับรถที่ OSRM เลือกว่าเร็วที่สุด จึงไม่จำเป็นต้องเป็นเส้นทางที่สั้นที่สุดหรือเส้นทางสำหรับมอเตอร์ไซค์โดยเฉพาะ
- ไม่แสดงออเดอร์ที่ไม่มีพิกัดปลายทาง พิกัดไม่ถูกต้อง หรือไม่สามารถหาเส้นทางไปถึงได้
- หากไม่พบออเดอร์จะส่ง `[]` กลับมา หาก OSRM ทำงานล้มเหลวจะตอบสถานะ `502` พิกัดต้นทางไม่ถูกต้องจะตอบ `400` และฐานข้อมูลทำงานล้มเหลวจะตอบ `500`
- API นี้ส่งระยะทางกลับมา แต่ยังไม่ได้ส่งข้อมูลเส้นทางสำหรับวาดเส้นบนแผนที่ ส่วน `/customers/nearby` ยังทำงานเหมือนเดิม

ค่าเริ่มต้นเรียกใช้เซิร์ฟเวอร์เดโมที่ `https://router.project-osrm.org` โดยไม่ต้องติดตั้ง OSRM หรือใช้ API key หากต้องการใช้เซิร์ฟเวอร์อื่นที่รองรับ OSRM ให้กำหนดตัวแปรสภาพแวดล้อมของ Backend ดังนี้:

```dotenv
OSRM_BASE_URL=https://your-osrm-server.example
```

หากหลายออเดอร์ใช้พิกัดลูกค้าเดียวกัน ระบบจะขอระยะทางของพิกัดนั้นเพียงครั้งเดียว แล้วนำผลไปใช้กับทุกออเดอร์ที่เกี่ยวข้อง หากมีพิกัดจำนวนมากจะแบ่งเป็นชุด ชุดละไม่เกิน 99 ปลายทางต่อคำขอ

การเรียกเซิร์ฟเวอร์เดโมเริ่มต้นจะเข้าคิวทีละคำขอ และเว้นระยะระหว่างการเริ่มคำขออย่างน้อย 1.1 วินาทีภายในโปรเซส Backend นี้ แต่ละคำขอไปยัง OSRM มีเวลารอสูงสุด 10 วินาที หากหาเส้นทางไม่ได้หรือเกิดข้อผิดพลาด ระบบจะไม่ใช้ระยะทางตรงแทน

เซิร์ฟเวอร์เดโมสาธารณะมีไว้สำหรับการใช้งานที่ไม่ใช่เชิงพาณิชย์ในปริมาณที่เหมาะสม และไม่รับประกันความพร้อมใช้งาน หากรัน Backend หลายโปรเซส ต้องใช้ระบบจำกัดอัตราคำขอร่วมกัน หรือเปลี่ยนไปใช้เซิร์ฟเวอร์ OSRM ที่จัดเตรียมแยกไว้

- [เอกสาร OSRM Table API](https://project-osrm.org/docs/v26.6.1/http#table-service)
- [ข้อกำหนดการใช้งานเซิร์ฟเวอร์เดโม](https://github.com/Project-OSRM/osrm-backend/wiki/Demo-server)

คำสั่งรันชุดทดสอบเฉพาะส่วนนี้ โดยจำลองฐานข้อมูลและ OSRM จึงไม่แก้ไขข้อมูลจริง:

```sh
npm test -- test/order-nearby.test.ts
```
